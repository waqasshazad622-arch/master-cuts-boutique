# Master Cuts Boutique — Website (v1)

Boutique website for **Master Cuts Boutique, Lal Kurti, Rawalpindi**.

- **Live site:** enable GitHub Pages on this repository (Settings → Pages → Deploy from branch `main`) — the site is a static single page.
- **Files:** `index.html` (page), `style.css` (design), `images/` (32 JPGs — poster frames + logo, uploaded via the GitHub website; the page references them as relative `images/*.jpg` paths). NOTE (Nov 2026): the site used to embed images as base64 data URIs in `index.html` because the GitHub connector can only push text files. That made the page 3.2 MB and slow on mobile, so the images were moved to separate files in `images/` (uploaded through github.com) and `index.html` now links them. Do NOT re-embed: `build.py`'s embed flow is retired. Any future image change needs the JPG uploaded via the GitHub website AND the matching `index.html` reference pushed via the connector.
